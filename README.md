# DDA Study Toolkit

Week-by-week study notes for **Database Design & Administration (IT1x23)** at NYP, based on the Oracle Academy Database Design course (DD 1-1 to 6-4).

- Week 1: Intro, data vs information, conceptual/logical/physical models, entities, relationships
- Week 2: ER diagramming conventions, ERDish, supertypes & subtypes
- Week 3: Transferability, relationship types, resolving M:N, CRUD, UIDs, 1NF
- Week 4: 2NF, 3NF, MySQL Workbench

Includes Barker-notation diagrams, reference images from the lecture pages and slides, classroom activity answers, an ERDish builder and a practice test.

Open `index.html`, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Images in `images/` and PDFs in `slides/` are Oracle Academy / course material (© Oracle).
